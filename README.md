# Array Lab

Интерактивный визуализатор сортировок на русском языке. Запуск без сборки: откройте `index.html` в браузере или запустите статический сервер, например `python3 -m http.server 4173`.

## Возможности

- Каталог из 350 вариантов на основе 35 разных алгоритмов сортировки: сравнение, распределение, слияние, выбор pivot, сортировки кучей, деревом, карманами и другие.
- «Нарисовать массив»: рисуйте значения мышью или пальцем на графике. После «Готово» выберите, сохранить массив или использовать только сейчас.
- «Своя анимация»: нарисуйте первый кадр, зафиксируйте его, затем рисуйте следующий. После завершения можно сохранить анимацию в каталоге или запустить без сохранения.
- Запуск, пауза, пошаговое выполнение, скорость, размер массива и поиск по каталогу.

Пользовательские массивы и анимации сохраняются локально в `localStorage` этого браузера.
